1. Installation

No build tools are required. Bootstrap 5.3, Bootstrap Icons and Google Fonts load from CDNs.

  1. Unzip wanderly-holidays.zip.
  2. Open pages/index.html directly, or run a local server so localStorage and form features behave like production: 
    cd wanderly-holidays
python3 -m http.server 8080
# open http://localhost:8080/pages/index.html
  3. Upload the full folder to your host. The root index.html redirects to pages/index.html. If your host lets you set a document root, you can also move the pages to the root and update the relative paths.

4. Colors & fonts

All colors, spacing, radii and shadows are CSS variables at the top of assets/css/style.css:

:root {
  --wh-primary: #f5b800;      /* the ONE brand colour (yellow) – buttons, highlights, active states */
  --wh-primary-600: #e0a800;  /* hover / pressed shade */
  --wh-primary-ink: #111111;  /* links & icons (black in light mode, yellow in dark mode) */
  --wh-on-primary: #111111;   /* text placed on yellow */
  --wh-font-display: "DM Serif Display", Georgia, serif;
  --wh-font-body: "DM Sans", system-ui, sans-serif;
}

The palette uses a single primary colour plus black/grey neutrals. Green and red are kept only for success and error messages. Dark mode (dark-mode.css) uses a true black background and keeps the same yellow, with links and icons switching to yellow. Keep text contrast at 4.5:1 or higher when changing colors (check with the WebAIM contrast checker).

Changing fonts

Replace the Google Fonts <link> in each page head and update the two font variables. To self-host, see assets/fonts/README.txt.

Spacing

Spacing follows an 8px scale: --wh-space-1 (8px) to --wh-space-12 (96px).

5. Content & packages

Package grids, details, booking summary and the dashboard all read from assets/js/plugins/packages.js:

{ "id": "kerala-backwaters", "title": "Kerala Backwaters & Hills",
  "dest": "Munnar, Alleppey, Kochi", "place": "Kerala", "region": "South India",
  "cat": "domestic", "theme": "hills", "tags": ["honeymoon", "family"],
  "days": 6, "nights": 5, "price": 28990, "old": 33500,
  "rating": 4.8, "reviews": 412,
  "incl": ["hotel", "meals", "sightseeing", "transfers"],
  "visa": null, "flight": false, "seed": "wh-kerala-houseboat", "alt": "…" }
  • Region values must match the filter checkbox values in the listing pages.
  • Currency: edit money() in main.js (default en-IN / INR).
  • Dashboard data (bookings, messages) is sample data at the top of dashboard.js. Replace it with API calls.
  • Package details shows hand-written Kerala content by default. Other packages get generated overview, itinerary, inclusions and hotels. Add richer fields to packages.js as needed.
  • Search the code for TODO to find every placeholder.

6. Images

Photos load from https://picsum.photos/seed/<name>/<w>/<h>.webp so the template works out of the box. Each seed is unique per section. Before launch:

  1. Export your photos as WebP at the sizes in each width/height attribute (keep those attributes to prevent layout shift).
  2. Put them in assets/images/ and replace the src values. In packages.js, update img() in main.js to point at your folder.
  3. Write descriptive alt text. Decorative background images use alt="".

Images below the fold use loading="lazy"; hero images use fetchpriority="high".

7. Forms & integrations

Validation

Add data-wh-validate novalidate to a form and wrap each control in .wh-field with an .invalid-feedback element. Custom messages: data-msg-required, data-msg-pattern, data-msg-min, data-match="#otherField". Tooltips use data-bs-toggle="tooltip".

While an action URL still contains YOUR_, forms validate and show a clear "demo mode" message instead of pretending to send.

Formspree

Create a form at formspree.io and replace https://formspree.io/f/YOUR_FORM_ID in contact, booking and blog comment forms.

Netlify Forms

Remove the action, add name="contact" data-netlify="true" netlify-honeypot="bot-field". The hidden form-name and honeypot fields are already in the contact form. main.js posts Netlify forms with fetch.

Mailchimp newsletter

Replace https://YOUR_ACCOUNT.us1.list-manage.com/subscribe/post?u=YOUR_U&id=YOUR_ID (footer, home and coming soon) with your embedded form action. Mailchimp's endpoint does not allow fetch from other domains, so either remove data-wh-validate to submit normally or use the post-json JSONP endpoint.

Google Maps

In contact.html, paste your Google Maps embed iframe inside .wh-map (a commented example is there) and delete the placeholder.

Booking calendar

The start date uses the native date picker with a minimum of 7 days ahead. To show live availability, swap #bDate for your calendar widget (e.g. a Flatpickr instance fed by your API) and keep the .wh-field wrapper.

Stripe & PayPal

Step 4 of booking.html contains two radio placeholders. For production:

  • Stripe: create a Checkout Session on your server and redirect, or mount the Payment Element in place of the Stripe option.
  • PayPal: load the PayPal JS SDK and render Smart Buttons into a container in step 4.
  • Only show the confirmation step after your server confirms the payment or booking request.

Login

The login form uses data-demo-login to open the sample dashboard. Replace it with your auth provider and protect pages/dashboard/ on the server.

8. Dark mode & RTL

A small inline script in each <head> applies the saved theme and direction before the page paints. Toggles use data-theme-toggle and data-dir-toggle. Storage keys: wanderly-theme, wanderly-dir, wanderly-saved.

To launch an Arabic or Hebrew site by default, set <html lang="ar" dir="rtl">. Custom components use logical CSS properties; rtl.css mirrors Bootstrap utilities and directional icons.

9. Accessibility

  • Skip link, one h1 per page and ordered headings
  • Visible 3px focus outline, 44px minimum touch targets
  • ARIA labels on icon buttons, aria-live on results, totals and errors, aria-current on navigation
  • Errors linked with aria-describedby; first invalid field receives focus
  • prefers-reduced-motion respected; motion reduced on phones

10. SEO & performance

  • Unique title (≤60 characters) and meta description (150–160 characters) on every page
  • JSON-LD: TravelAgency (all pages), ItemList + Product/Offer (home, listings, offers), Product + FAQPage (details), Blog/BlogPosting
  • Open Graph and Twitter tags, canonical URLs, sitemap.xml, robots.txt (dashboard disallowed and noindexed)
  • Replace https://www.wanderlyholidays.com with your domain in pages, sitemap and robots
  • For PageSpeed 90+: serve your own compressed WebP images, self-host fonts, and enable caching and compression on your host. Image dimensions are set to keep CLS under 0.1.
