Self-hosting fonts (optional, recommended for PageSpeed)
=========================================================
By default the template loads DM Serif Display + DM Sans from Google Fonts.
To self-host:
1. Download the WOFF2 files (e.g. https://gwfh.mranftl.com/fonts) into this folder.
2. Add @font-face rules at the top of assets/css/style.css.
3. Remove the Google Fonts <link> tags from each page's <head>.
